# Cognitive Assessment Lab v3
Personal offline Android practice app for the Capgemini cognitive assessment.

Modules:
- Motion Challenge — 6 min
- Grid Challenge — 12 min
- Logical Reasoning — ~25 min
- Behavioural Module — 25 min

The implementation uses original assets/code and public/reference mechanics. It is not an official Aon or Capgemini application.

## Build
Open the `cognitive-assessment-lab` directory in Android Studio, or push the branch and let GitHub Actions build `app-debug.apk`.

## APK
The workflow uploads `app-debug.apk` as the `cognitive-assessment-lab-debug` artifact.
